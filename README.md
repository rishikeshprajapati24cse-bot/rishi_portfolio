# Rishikesh Prajapati — Personal Portfolio

A responsive personal portfolio project built with:

- HTML5
- Bootstrap 5.3.6 (included locally)
- Custom CSS
- JavaScript
- Uploaded profile photo

## Files

- `index.html` — main portfolio page
- `css/style.css` — custom styling and animations
- `js/script.js` — typing effect, theme switcher, scroll reveal, filters, progress bar, active navigation
- `bootstrap/css/bootstrap.min.css` — local Bootstrap CSS
- `bootstrap/js/bootstrap.bundle.min.js` — local Bootstrap JS bundle
- `assets/profile.jpg` — profile photo supplied for this project

## Run locally

1. Extract the ZIP.
2. Open `index.html` in a browser.

For the best experience, use VS Code + Live Server, or any simple local HTTP server.

## Free hosting

### GitHub Pages
1. Create a GitHub repository.
2. Upload all files/folders from this project.
3. Go to **Settings → Pages**.
4. Select the `main` branch and `/root` folder.
5. Save. GitHub will provide the live website URL.

### Netlify
1. Open Netlify.
2. Choose **Add new site → Deploy manually**.
3. Drag the extracted project folder into the upload area.
4. Netlify will generate a live URL.

No build step is required.
